# 課題と価値仮説 — ひばりが丘FC のクラブの連絡

ひばりが丘FC の代表の夜と週末を削っているのは、出欠を集める手段が無いことではない。予定とその変更を置いておく、全員が見に行く一か所が無く、欠席や車の変更の受け付け、代わりの手配、配り直し、問い合わせへの返事が、すべて代表の個人の LINE に集まることである。そこで、アプリを作る前に、次の4週間、何も作らずに LINE グループの使い方だけを変え、保護者とコーチが変更を代表の個人の LINE ではなくグループの決まった投稿へ出すかどうかを確かめる。

依頼は、代表から「出欠をボタン一つで集めるアプリを作りたい。できれば当番の割り振りと会費の集金も」という形で届いた。この文書は、代表と、手伝いを申し出ている知り合いのエンジニアが、何かを作り始める前に何を確かめるかを決めるために読む。依頼者は「保護者の返事が遅い」ことを困りごとの中心に置いていたが、直近の出来事から見えたのは返事の遅さではなく、連絡の行き先が代表一人になっていることだった。当番と集金は、出来事がまだ無いので仮説のまま残した。何を作るか、クラブが長く何を目指すかは、この文書では決めない。

## 起きていること

クラブは小学生40人くらい、35家庭くらいで、コーチも代表も保護者のボランティアである（出典：依頼の文）。連絡は全家庭が入った LINE グループと、個人の LINE で回っている。以下の出来事は、どれも 2026-09-27 に代表から聞いた。

### 代表は、試合の前夜に一人で配車を組み直していた

練習試合の前夜の 2026-09-19（金）、21時半すぎから23時ごろにかけて、代表の個人の LINE に三家庭から別々に連絡が来た。二家庭は子どもの発熱で休むという連絡、一家庭は仕事が入って車を出せなくなったという連絡で、LINE グループには誰も書いていなかった。配車表（誰の車に誰が乗るか）は代表が前日の木曜の夜に自分の表計算で作り、グループに流してあった。車が1台足りなくなったため、代表は23時すぎから車を出せそうな家庭に一軒ずつ個人の LINE と電話で頼み、4軒目で引き受けてもらえた。配車表を作り直してグループへ流し直したのは午前0時40分ごろである。翌朝、流し直した配車表を見ていなかった家庭が1軒あり、集合場所で子どもの乗る車が分からず、出発が15分遅れた。（出典：代表の発言、観測時点：2026-09-27）

翌日の 2026-09-20（土）の試合中も、代表は前半のあいだ、グラウンドの脇で翌週の配車表の下書きをしていた。コーチとしてグラウンドに立ちたいという依頼の思いは、この時間に削られている。（出典：代表の発言、観測時点：2026-09-27）

### 代表は、解決策を探すのにも週末を使っていた

代表はこの春、市販の出欠アプリを三つ調べ、それに週末を一つ使った。これだけの手間をかけていることが、課題の重さを示している。（出典：代表の発言、観測時点：2026-09-27）

### 代表は、グループに流した情報を一人ずつ答え直していた

2026-09-08（火）の夜、コーチの一人と保護者の2人から、別々に個人の LINE で「土曜の集合時間は何時でしたっけ」と聞かれた。集合時間はグループに流してあったが、ほかの話題で流れていた。代表は3人にそれぞれ返事をし、その夜クラブの連絡に使ったのはおよそ1時間半だった。（出典：代表の発言、観測時点：2026-09-27）

### 代表は、個人の LINE に届いた問い合わせを見落としていた

2026-08-23（日）、代表は朝6時に雨で練習の中止を決め、6時10分にグループへ流した。3家庭はそれを見ずに子どもを連れてグラウンドに来たので、代表もグラウンドへ行き、謝って帰ってもらった。そのうちの1家庭からは後で、前の晩に個人の LINE で「明日は雨でも来るのか」と聞いたのに返事がなかったと言われた。代表はその連絡を、たくさんの個人の連絡に埋もれて見落としていた。（出典：代表の発言、観測時点：2026-09-27）

### 保護者と会計の保護者の困りごとは、まだ本人から聞けていない

保護者の側で起きたこと（集合場所で乗る車が分からなかった、雨の中グラウンドへ来た）は、どれも代表を通して聞いた出来事で、保護者本人がそれをどう受け止め、なぜ変更をグループではなく代表の個人の LINE へ送ったのかは聞けていない。

「保護者はみんな返事が遅い」という困りごとについて、代表は直近の一回を思い出せなかった。出欠の締め切りを決めて告知したことも無いと話している。繰り返しの自己申告なので、この文書では出来事に数えない。（出典：代表の発言、観測時点：2026-09-27）

会計の保護者（Bさん）は、毎月の会費の集金で、現金を持ってこない家庭に個別に催促し、月に2時間ほどを集金に使っている。集金はクラブの二つ目の大きな課題である。（出典：代表の発言、観測時点：2026-09-27）

## 本質は、予定と変更の行き先が代表一人になっていること

クラブの予定とその変更には、全員が見に行く決まった置き場所が無い。グループに流した情報はほかの話題で流れるので、確かめたい人も変えたい人も、確実に届く代表の個人の LINE へ送る。その結果、変更を受け、代わりを手配し、作り直した表を配り、同じ問い合わせに答え直す役が、すべて代表一人に集まる。

この一つの原因で、観測した症状のほとんどを説明できる。9月19日に三家庭の変更が個人の LINE にだけ届いたこと、代表が深夜に一人で車を探して表を作り直したこと、流し直した表を見ていない家庭が出て出発が遅れたことは、どれも確定版の置き場所が無く、変更の窓口が代表だけであることから起きている。9月8日の集合時間の問い合わせは、グループに流した情報が見つからないので代表へ聞いた結果で、8月23日の見落としは、個人の LINE に集まった連絡が代表一人の処理量を超えた結果である。9月20日の試合中の配車表の下書き、平日の夜がつぶれること、試合の前日に寝られないことも、配車の組み立てと変更の処理を代表だけが抱えていることの表れと見る。



## 出欠アプリは、欠席の集約には効くが、配車の組み直しと配り直しは残す

代表が出欠アプリを思いついたのは、欠席の連絡がばらばらに届き、それを集める手間を無くしたかったからだと読める。欠席が一か所に集まれば、9月19日の二家庭の欠席は代表の個人の LINE を通らずに済む。

しかし、車を出せなくなった家庭の代わりを探す手間、作り直した配車表を全員に行き渡らせる手間、流れた集合時間の問い合わせは、出欠のボタンだけでは残る。そもそもアプリが効くかどうかは、保護者が代表の個人の LINE ではなくアプリへ変更を出すかに懸かっており、それは今の LINE グループでも確かめられる同じ前提である。依頼にある「返事の遅さ」は出来事で裏付けられていないので、それを解く機能を作る根拠はまだ無い。当番の割り振りと会費の集金は、上で書いたとおり出来事が無く、この本質では評価できない。

## 価値仮説

代表が出欠をボタン一つで集めるアプリと、当番の割り振りと集金の機能を使えれば、クラブの連絡が楽になる。

## 確かめる方向

### 予定の確定版を一か所に置き、変更は本人がそこへ出す

試合や練習ごとに、集合時間、場所、配車を載せた確定版を、グループの中で流れずに見える決まった場所（LINE のアナウンスやノートなど）に一つだけ置き、欠席や車の変更は本人がそこへ書き込む。確定版を見に行けば分かるので、9月8日のような問い合わせと、9月19日の流し直しの見落としに効くと見込む。変更が代表個人を通らなくなれば、8月23日のような見落としも減る。

### 配車の穴を代表以外が埋める

変更で車が足りなくなったとき、代表が一軒ずつ頼むのではなく、確定版を見た家庭が自分から名乗り出る形にする。9月19日の深夜の手配と、9月20日の試合中の下書きに効くと見込む。一つ目の方向で変更が全員に見えることが、この方向の前提になる。

## 前提と危うさ

四つのリスクに点数を付けた。価値は影響5・根拠1、実現性は影響4・根拠1、使いやすさは影響2・根拠2、事業性は影響2・根拠3で、合計の高い順に確かめる。

価値の前提は、保護者とコーチが、欠席や車の変更を代表の個人の LINE ではなく全員に見える場所へ出すことである。これが崩れれば、アプリを作っても LINE の使い方を変えても変更は代表に集まり続け、価値仮説がまるごと崩れる。根拠は無い。9月19日の三家庭はそろって個人の LINE を選んでおり、なぜそうしたのか（グループに書くのに気が引けるのか、代表に確実に届けたいのか）は本人から聞けていない。四つの中でいちばん影響が大きく、根拠が弱い。

実現性の前提は、変更で車が足りなくなったとき、代表以外の家庭が自分から名乗り出ることである。崩れれば二つ目の方向は成り立たず、深夜の手配は代表に残る。9月19日に4軒目で引き受けてくれた家庭がいたので車を出せる家庭がいることは分かっているが、頼まれずに名乗り出るかは分からない。影響は大きく、根拠は価値の前提と同じくらい弱い。

使いやすさの前提は、確定版を置いた決まった場所を、保護者が前日や当日の朝に見に行くことである。9月19日に流し直した表を見ていない家庭が1軒あったので、見に行かない家庭は出る。ただし、確定版が一つに決まっていれば、見ていない家庭への個別の声かけは代表以外にもできるので、崩れたときの影響は上の二つより小さい。

事業性の前提は、この回し方を、ボランティアの代表が負担なく続けられることである。確定版を置く手間が今の配り直しより軽いと推定しているが、確かめていない。崩れても方向の中身を軽くすれば直せるので、最初には確かめない。

## 最初に確かめること

価値の前提と実現性の前提は、崩れたときの影響と根拠の弱さが並ぶ。どちらも同じ小さな方法で同時に確かめられるので、まとめて最初に置く。

次の4週間、何も作らずに、代表が試合や練習のたびに LINE グループの決まった場所へ確定版を一つ置き、「欠席と車の変更は、代表の個人の LINE ではなくこの投稿へ。車が足りなくなったら、出せる方は名乗り出てください」と一度だけ頼む。その間、前日18時以降から当日の出発までに、欠席と車の変更が決まった場所と代表の個人の LINE のどちらに何件届いたか、集合時間などの問い合わせが代表個人に何件来たか、車が足りなくなったときに誰が埋めたかを、代表が日ごとに書き留める。

変更の半分以上が代表の個人の LINE に届き続けたら、価値の前提は崩れたとする。そのときは、個人の LINE へ送った保護者に、その一回でなぜグループではなく代表へ送ったのかを聞き、本質から書き直す。車の不足が起きた回に、代表が頼む前に誰も名乗り出なければ、実現性の前提は崩れたとし、二つ目の方向を外す。変更の半分以上が決まった場所に届き、名乗り出る家庭が一度でも出れば、両方の前提を残し、次に危うい前提を選び直す。4週間の間に車の不足が一度も起きなければ、実現性の前提は未確認のまま残す。

## 未決

### 保護者はなぜ変更を代表の個人の LINE へ送るのか

9月19日の三家庭がグループではなく代表個人へ送った理由は分かっていない。気が引けるのか、代表に確実に届けたいのかで、確定版の置き場所だけで足りるかが変わる。確認先・方法：上の4週間の後、代表の個人の LINE へ変更を送った保護者に、最近の一回について聞く。

### 保護者の返事は本当に遅いのか

代表の自己申告だけで、直近の一回が出ていない。締め切りを決めて告知したことも無い。確認先・方法：出欠に締め切りを決めて一度告知し、締め切りまでに返事の無い家庭が何軒あるかを数える。

### 会計の保護者の集金の手間は何か

代表の又聞きの一言だけである。本質とは別の課題かもしれない。確認先・方法：会計のBさん本人に、最近の集金の一回で何をし、どれだけ時間を使ったかを聞く。

### 当番は偏っているのか

依頼で当番の割り振りに触れているが、出来事を聞けていない。確認先・方法：当番を誰がいつやったかを1か月記録してから、偏りが課題かを判断する。この方法は grill で問わずに残した推奨で、依頼者はまだ合意していない。
