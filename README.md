- `product-north-star-planning@product-planning`: `grill@grill`、`product-north-star@product-planning`、`write-doc@write-doc`、`intermediate-cleanup@product-planning`
- `product-strategy-planning@product-planning`: `product-context@product-planning`、`grill@grill`、`product-strategy@product-planning`、`strategy-critique@product-planning`、`write-doc@write-doc`、`intermediate-cleanup@product-planning`
