# プロダクトの現在地を読む規律

`map-context`で同じagentが適用する。ここでは戦略を決めず、意思決定時点の証拠と課題候補を整理する。

- **事実**: 出典と観測時点を示せる観測内容。解釈を混ぜない。
- **仮説**: 未検証の説明または予測。反証方法を添える。
- **未確認事項**: 判断に影響する問い。確認先または確認方法を添える。
- **制約**: 選べる経路を現実に狭める条件。不満や結論と分ける。
- **能力**: 現に使える強み、資産、権限、学習速度。願望を数えない。
- **機会**: 外部変化または未充足価値から生じる可能性。確実な需要と断定しない。

課題候補は、現状が顧客や事業に既に生んでいる問題と、North Starへ進む際の障壁の両方から洗い出す。症状と原因候補を分け、どの事実・仮説・未確認事項に基づくかを示す。価値提供が活動の連鎖で決まる場合は、全体を止める最も弱い環と前後の依存も候補へ含める。ここでは最重要課題を選ばない。
