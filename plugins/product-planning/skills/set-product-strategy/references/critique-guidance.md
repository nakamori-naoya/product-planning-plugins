# 戦略反証の規律

`critique`で入力戦略を直接編集せず、主張、根拠、反証、重大度、修正要求を対応づける。可能なら作成時の会話を持たない別の評価文脈で行い、それを独立評価と呼ぶ。同じagentが同じ文脈で行う場合は、入力、North Star、現在地、対話の決定を保持したまま作成者の視点から反証者の視点へ切り替える批評passであり、独立評価とは呼ばず、その制約を反証の `## 制約・根拠・鮮度` に明記する。証拠文脈を捨てず、別agentへ意味判断を委譲しない。

次のいずれかがあれば `要修正` とする。

- 最重要課題が選ばれていない。
- 診断と基本方針が接続しない。
- 基本方針が選択を生まず、何も捨てない。
- 一貫した行動が相互補強しない。
- 全体を止める弱い環を外している。
- 近い目標が手の届く行動へ翻訳されていない。
- 資源配分がない。
- 制約または根拠を捏造している。
- North Starへ接続しない。

軽微な表現改善だけなら `合格` にできる。`合格`でも未検証の見立てと方針を見直す条件を残す。
